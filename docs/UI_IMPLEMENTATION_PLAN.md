设计选择：内联按钮配合持久化输入步骤；保留命令兼容。每个按钮使用不可猜测随机 token，绑定 actor、菜单代次、权限、期限和实际发送消息。回调检查 Telegram 绑定机器人、本人私聊、message_id、当前权限及业务版本；新屏幕/命令使旧按钮失效。更新、callback_id 和一次性 action 均持久化去重，事务失败不确认游标。

人工调整不是支付成功证明，也不是异常充值自动补账：不得修改 payments 或解除身份隔离。确认页记录当前余额快照；确认时余额变动则要求重新核对，避免展示余额与实际调整不一致。原因长度最多 500 UTF-16 单位；UI 每页最多 8 项，按钮 token 30 分钟过期。管理员输入态撤权后拒绝并清理，不把敏感输入误当回执或个人草稿材料。
